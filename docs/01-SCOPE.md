## 1. 一句话

做一个**能长时间挂机、也能认真打架**的修仙桌面客户端：日志读得下去，面板点得动，
断了能自己接上，一个 exe 拷走就能跑。

## 2. 形态：Rust + 原生 GUI（egui）

| 项 | 选择 | 理由 |
|---|---|---|
| 语言 | Rust（edition 2024） | 单 exe、无运行时；异步与 WS 生态成熟；崩溃面比脚本小 |
| 界面 | egui + eframe 0.37（wgpu 后端） | 即时模式，界面直接由服务端帧驱动；自带表格/图表/滚动区/IME/可访问性 |
| 并发 | tokio（rt-multi-thread） | 一条读、一条写、一个 tick；与心搏/超时对齐 |
| 传输 | tokio-tungstenite + rustls | 直连服务端 `/ws`，不依赖系统 OpenSSL |
| 序列化 | serde + serde_json | 协议是 JSON；未知字段默认忽略 |
| 平台 | Windows / macOS / Linux | 首版三平台；Windows 是当前开发机 |

**为什么不是网页**：网页要引入浏览器内核（Tauri/Electron 都是这条路），发布体积从 20MB 涨到 100MB+，
还要处理跨域、字体、滚动性能与安全更新。这个游戏的界面不值得背一个 Chromium/WebView2。

**为什么不是终端（TUI）**：TUI 版设计已作废。终端能做到"能玩"，但做不到这几件事——
富文本日志里的颜色分层与可选中复制、交易行按列排序、价格曲线、DPI 缩放、
不同字号与中文字体回退。这些恰好是这个游戏每天都要看的东西。
TUI 的优势（体积、低内存）抵不过"每天盯着看"的体验差距。

**为什么是 egui 而不是 iced / slint**：

| 候选 | 不选的原因 |
|---|---|
| `iced` | Elm 架构要维护消息与组件树；日志是每秒追加的流，逐条转成消息反而绕 |
| `slint` | 多一门 DSL 与构建步骤；富文本日志要自绘；授权是 GPL/商业双轨 |
| `Tauri` | 本质是网页，见上一条 |
| `gtk-rs` / `fyne` | 依赖系统库，三平台打包与字体一致性都更难 |

## 3. 目标（M1–M5）

1. **主循环可玩**：登录 → 建号 → 看节点 → 赶路 → 历练 → 打坐 → 突破。
2. **战斗可读**：多人遭遇、目标选择、战报逐行播放、秘境分层与掉线重连。
3. **社交与经济可用**：聊天、好友、师徒、队伍、交易行、邮件。
4. **宗门与拍卖可用**：建宗/捐献/宗门战报名与战报、拍卖出价与一口价。
5. **实时切磋**：`live` 帧驱动的回合制对战，15 秒窗口、倒计时、认输。

## 4. 非目标（首版明确不做）

| 不做 | 原因 |
|---|---|
| 网页版 / 内嵌 WebView | 首版是原生窗口；发布体积与安全面都不可接受 |
| 终端界面（TUI） | 已作废，见 §2 |
| 本地战斗计算 | 服务端是唯一事实源；客户端只播 `battle` / `live` / `pvpResult` |
| 离线收益模拟 | 离线收益由服务端在 `ready.offline` 给出 |
| 宏 / 自动脚本 | 与服务端限流和"手动选择"的玩法前提冲突 |
| 多账号同屏 | 一账号一连接（顶号机制）；多开会互相顶掉 |
| 音频 / 3D | 首版只有 2D 绘制与文字；音效留到 M5 之后再看 |
| 移动端 | 桌面优先；触屏布局不在首版 |
| 多语言 | 文案全部中文；字体只内置简体子集 |

## 5. 成功标准（可验收）

- 冷启动到可操作 ≤ 3 秒（含字体加载与首帧；SSD 机器）。
- 主循环（登录 → 移动 → 战斗一场 → 打坐）无卡顿、无 panic、无空白窗口。
- 断线重连：3 秒内恢复；秘境掉线在 5 分钟内回同层（服务端口径）。
- 版本不兼容（关闭码 4004）时给"升级客户端"的明确提示，且**不进入重连循环**。
- 连续挂机 2 小时，RSS 不持续增长（日志环形缓冲 + 表格虚拟化）。
- 窗口 1024×640 到 2560×1440、系统缩放 100%–200% 下布局不错位、文字不模糊。
- Windows/macOS/Linux 各一个可执行产物，不要求用户装运行时。

## 6. 依赖与前置

- 服务端可连：`/healthz` 200、`/ws` 可握手。
- 手里要有：服务端 `docs/05`（字段）、`docs/12`（流程）、本目录 `C-03`（连接策略）。
- 显卡：支持 Vulkan / DX12 / Metal / OpenGL 3.3 其一即可；纯软件环境退回 glow 后端（`C-02` §6）。
- 系统字体不是依赖：中文用内置子集字体，缺失字形再回退系统字体。
