## 1. 分档原则

- 每一档都能**独立可玩**，不是"半成品拼到最后一起验收"。
- 每档结束跑一次 `C-08` 的自查清单 + `cargo test` / `clippy` / `doc-check`。
- 涉及协议面的档，先在服务端仓库里找到对应的验收脚本，照着它的输出对字段。
- 每档都给一个能双击运行的 release 包；不给"只有开发机能跑"的中间态。

## 2. M1 · 窗口骨架与主循环

**工程**：`Cargo.toml`（eframe/tokio/serde 骨架）、`protocol/` 全部帧类型、`net/ws.rs` 握手与重连、
`store/` 基础结构、`app.rs` 的 drain→Intent→绘制循环、`ui/theme.rs` 与 `ui/fonts.rs`、
登录页/建号页/主界面三栏/日志区/出口列表/状态栏/输入栏（只发世界频道）。

**玩法**：登录、建号、`ready` 目录、日志、状态条、出口列表、移动、历练、打坐、突破。

**完成定义**

- 冷启动到"能移动"不超过 3 秒（release 包，SSD）。
- 窗口 1024×640 与 1280×800 下布局都不截断；125% 缩放下文字清晰。
- 待机（无倒计时）CPU < 1%，不持续重绘。
- `move` 有倒计时，到达前出口列与地点动作置灰；地形门槛在出口行就能看到缺什么。
- 打坐开关与 `vital` 校准一致；突破失败有明确文案。
- 断网 3 秒内自动重连，重连后 `ready` 整体替换状态；顶栏灯色正确。
- 日志 5000 行时滚动跟手，上滚不被新行抢位置。

## 3. M2 · 战斗与秘境

**工程**：`store/fight.rs`、`ui/widgets/` 的怪卡/血条/技能按钮/倒计时环、战斗面板滑入动画、战报淡入队列。

**玩法**：`battle`（单怪/三怪/组队）、目标选择、逐行战报、秘境进出与切层、掉线重连回层。

**完成定义**

- 三怪场景能按序号或点击选目标；目标死亡自动切下一只；`over` 后控件禁用。
- 战报逐行 140ms 淡入，`Esc` 可跳过；跳过不影响状态。
- 秘境掉线 5 分钟内重连能回到同层同进度；清层不自动推进。
- 团灭与通关的文案、次数变化与服务端一致。
- 队友血条只在有数据时出现。

## 4. M3 · 社交与经济

**工程**：`store/social.rs`、`egui_extras` 表格封装（排序/筛选/列宽持久化）、`egui_plot` 曲线、邮件双栏、Toast 队列。

**玩法**：聊天四频道与屏蔽、好友/师徒/关系、队伍与掉落模式、交易行、邮件、拍卖。

**完成定义**

- 好友离线申请、离线收信都能重连后看到。
- 交易行费率与在售上限来自帧，不写死；自己不能买自己的单（按钮置灰）。
- 抽签公告原样展示（含两人点数与得主）。
- 价格曲线 `null` 断线处理，不补 0；悬停能读出当天均价与成交量。
- 表格排序/筛选/列宽在切页后保留；200 行以内不分页。

## 5. M4 · 宗门、拍卖与实时切磋

**玩法**：宗门建/捐/审批/名单、宗门战全流程、拍卖出价/一口价、`live` 实时切磋。

**完成定义**

- 宗门战名单锁定后不可改，锁定态在界面上明确；战果双方可读。
- 拍卖被超价后余额正确退回（刷新 `state` 后一致）；到期结算不本地伪造。
- 实时切磋：15 秒倒计时准确（误差 ≤ 200ms），双方出手才推进，认输/掉线/超时都有明确结果与原因。
- 切磋中切页/缩放窗口不打断倒计时，回到主视图状态正确。

## 6. M5 · 打磨与发布

**范围**：浅色主题、界面缩放档位、可访问性（Tab 顺序/焦点框/减少动态效果）、
快照测试补全、日志搜索与多选复制、窗口尺寸记忆、三平台打包（Windows 图标与版本信息、macOS `.app`、Linux `.desktop`）、
性能记录与长挂机报告。

**完成定义**

- 2 小时挂机 RSS 平稳（增长 < 15%）；待机 CPU < 1%。
- 1024×640 到 2560×1440、100%–200% 缩放全部可用。
- 浅色主题下正文对比度 ≥ 4.5:1。
- 所有拒绝都有具体原因，不出现"操作失败"。
- 三个平台各一个可双击运行的产物，README 写清如何放行 SmartScreen / Gatekeeper。
