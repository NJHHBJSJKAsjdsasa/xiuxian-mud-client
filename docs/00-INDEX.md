## 1. 这个仓库是什么

客户端是**独立仓库**：`git@github.com:NJHHBJSJKAsjdsasa/xiuxian-mud-client.git`，
放在工作区根目录的 `client/`，与服务端仓库（`xianxia/`）完全分离。

| 路径 | 内容 |
|---|---|
| `*.go` | 客户端源码（`main` / `proto` / `net` / `state` / `app` / `keys` / `screen` / `widgets` / `render` / `pages` / `text` / `theme` / `gui_windows` / `gui_other`） |
| `go.mod` / `go.sum` | 依赖三个：`gorilla/websocket`、`golang.org/x/term`、`golang.org/x/sys` |
| `docs/` | 客户端设计文档（本目录） |
| `README.md` | 客户端工程的入口说明（怎么跑、键位、技术栈） |
| `tools/doc-check.py` | 文档矩阵与链接自查（本仓库自带，不依赖服务端） |

分离的代价是"协议变了要两边各改一次"。用两道闸门兜住：服务端 `docs/05` 是字段唯一来源，
本仓库只写用法；真出现破坏性变更时靠 `hello.proto` 握手在连接时挡住（关闭码 4004）。

## 2. 形态：Go 终端程序（仪表盘 TUI）

**Go 写的终端程序，界面是盒子化仪表盘，不是网页，也不再有字符山水。**

单二进制、无渲染后端、无资源目录：`go build` 完直接在终端里铺满，SSH 上去也能玩。
渲染是手写的 ANSI：没有 TUI 框架，布局、边框、量表、按键全部由本仓实现。
Windows 双击 exe 默认把同一块字符屏放进原生窗口（GDI）；`--tui` 强制终端。

- 不嵌 WebView：没有 HTML/CSS/JS，也没有 Node 运行时。
- 要一个 UTF-8 终端：80×24 起，Windows Terminal / iTerm2 / 任意 xterm 都行。
- 分层清晰（`C-02`）：协议、连接、状态、交互、绘制各管一段，绘制层只读状态。
- 界面规格见 `C-05`：标题栏 + 状态盒 + 去处盒 + 见闻盒 + 目标行 + 按键行，窄屏自动折叠。

## 4. 边界：谁是事实

- **协议字段、动作、错误码、关闭码的唯一来源是服务端 `docs/05-PROTOCOL.md`**；`docs/12-API.md` 是接入方视角的手册。
- 本目录只写"客户端怎么用这些事实"，**不复写字段表**。字段变了改服务端文档，客户端文档只在用法受影响时更新。
- 数值（伤害、体力、秘境次数、切磋回合上限）同理：以服务端 `docs/04-NUMBERS.md` 为准，客户端不内置第二份阈值。

## 5. 版本与变更

- 文档版本走 `x.y.z`：`x` 换形态或平台、`y` 加文档或改分工、`z` 改错别字与措辞。
- 每次改动同步本文件的矩阵与下方变更记录；不同步视为没改完。
